# bme280-driver
This repository hosts the source code for the Linux kernel module designed to provide support and enable integration for the Bosch BM280 sensor.
## Key features
  1)humidity, pressure and temperature abailable trought SYSFS.
  2)used interface : SPI.
  3)configuration trought DTB.
  4)characteristic files abailables in sysfs for each physic magnitud.
